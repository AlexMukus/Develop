## Примечания

- Скиллы `speckit-*` — это GitHub Spec Kit (шаблоны команд `templates/commands/*.md`), требуют структуру `.specify/` (в проекте присутствует: templates, scripts, memory, templates).
- Все speckit-скиллы поддерживают хуки из `.specify/extensions.yml` (в проекте не создан — хуки пропускаются).
- Дубли этих скиллов существуют в user-scope (`C:/Users/lobovav/.kimi-code/skills/`) — приоритет имеет проектная копия, но содержимое идентично.
- Типовой цикл: `constitution` → `specify` → `clarify` → `plan` → `tasks` → `analyze` → `checklist` (опционально) → `implement` → `converge` → `implement` → `taskstoissues` (опционально). Скилл `csharp-desktop-rules` применяется параллельно на всём протяжении работы с кодом.
